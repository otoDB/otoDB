# Theme colors

Reference for every theme's palette, generated from `src/themes.json` — the single source of
truth also used by the `postcss-map` plugin (see `postcss.config.js`) that expands these colors
into `src/themes.css`. Editing `themes.json` updates both the app and this page; there is no
separate value to keep in sync by hand.

The `default` theme follows the OS `prefers-color-scheme` and is omitted here since its colors
vary by machine.

## Text on background

How each theme's content and highlight colors read on top of its own backgrounds.
`highlight-primary` / `highlight-secondary` mark a "currently selected" accent, as an alternative
to ad-hoc uses of `content-primary` or `bg-fainter`.

{themeColors.map((t) => (

  <div key={t.name} style={{ marginBottom: '1.5rem' }}>
    <strong>{t.name}</strong>
    <div style={{ display: 'flex', gap: '0.5rem', marginTop: '0.25rem' }}>
      {[
        ['bg-primary', t.bgPrimary],
        ['bg-faint', t.bgFaint],
        ['bg-fainter', t.bgFainter]
      ].map(([label, bg]) => (
        <div key={label} style={{ background: bg, padding: '0.5rem', flex: 1 }}>
          <div style={{ color: t.contentPrimary, fontWeight: 'bold' }}>Heading</div>
          <div style={{ color: t.contentFaint }}>Faint on {label}</div>
          <div style={{ color: t.contentFainter }}>Fainter on {label}</div>
          <div style={{ display: 'flex', alignItems: 'center', gap: '0.375rem', marginTop: '0.375rem' }}>
            <span
              style={{
                display: 'inline-block',
                width: '0.75rem',
                height: '0.75rem',
                borderRadius: '9999px',
                background: t.highlightPrimary
              }}
            />
            <span style={{ color: t.highlightPrimary, fontWeight: 'bold' }}>
              Highlight primary on {label}
            </span>
          </div>
          <div style={{ display: 'flex', alignItems: 'center', gap: '0.375rem', marginTop: '0.25rem' }}>
            <span
              style={{
                display: 'inline-block',
                width: '0.75rem',
                height: '0.75rem',
                borderRadius: '9999px',
                background: t.highlightSecondary
              }}
            />
            <span style={{ color: t.highlightSecondary, fontWeight: 'bold' }}>
              Highlight secondary on {label}
            </span>
          </div>
        </div>
      ))}
    </div>
  </div>
))}
